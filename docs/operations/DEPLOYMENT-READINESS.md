# Deployment Readiness

A release requires green tests/lint, accepted API compatibility, migration rehearsal, environment validation, secret provisioning, secure host/proxy settings, health and structured logs, media/static validation, contact delivery behavior, preview/rebuild protection, scheduled-publish validation, backup/restore proof, smoke tests, monitoring, staged rollout, and a tested rollback or forward-recovery path.

The presence of legacy deployment scripts is not deployment readiness.
