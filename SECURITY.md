# Security

Report vulnerabilities privately to the repository owner. Do not publish credentials, personal data, unpublished content, exploit details, or production configuration.

Production requires strong secret material, explicit allowed hosts, secure cookies and transport, PostgreSQL credentials, controlled media access, sanitized rich content, protected preview/rebuild secrets, MFA policy, authorization on every privileged action, redacted structured logs, backups, and tested restore procedures.

Never weaken middleware, authentication, CSRF, validation, file inspection, or permission checks to make a test or frontend flow pass.
